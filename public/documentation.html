Documentation de l'API Russell

Cette documentation présente l'API Russell, une application permettant de gérer les catways et les réservations d'un port de plaisance.

Retour à la page de connexion

1. Overview - Présentation

L'API Russell permet de gérer les catways d'un port de plaisance ainsi que les réservations associées.

Les principales fonctionnalités sont :

  • Consulter la liste des catways.
  • Consulter les informations d'un catway.
  • Ajouter, modifier et supprimer un catway.
  • Consulter les réservations d'un catway.
  • Créer et supprimer une réservation.
  • Authentifier les utilisateurs.

2. Tutorial - Utilisation

Pour utiliser l'API, l'utilisateur doit d'abord se connecter avec une adresse e-mail et un mot de passe.

  1. Ouvrir la page d'accueil de l'application.
  2. Saisir ses identifiants dans le formulaire de connexion.
  3. Se connecter pour accéder au tableau de bord.
  4. Choisir la gestion des catways ou des réservations.

Les routes protégées nécessitent un jeton d'authentification JWT transmis dans l'en-tête Authorization.

3. Examples - Exemples

Gestion des catways

  • GET /catways : consulter tous les catways.
  • GET /catways/:id : consulter un catway.
  • POST /catways : ajouter un catway.
  • PUT /catways/:id : remplacer les informations d'un catway.
  • PATCH /catways/:id : modifier certaines informations d'un catway.
  • DELETE /catways/:id : supprimer un catway.

Gestion des réservations

  • GET /catways/:catwayNumber/reservations : consulter les réservations d'un catway.
  • GET /catways/:catwayNumber/reservations/:id : consulter une réservation.
  • POST /catways/:catwayNumber/reservations : créer une réservation.
  • DELETE /catways/:catwayNumber/reservations/:id : supprimer une réservation.

Exemple de création d'une réservation

4. Glossary - Glossaire

  • API : interface permettant à des applications de communiquer entre elles.
  • Catway : emplacement d'amarrage pour un bateau.
  • CRUD : opérations de création, lecture, modification et suppression.
  • HTTP : protocole utilisé pour les échanges entre le client et le serveur.
  • JWT : jeton utilisé pour authentifier un utilisateur.
  • MongoDB : système de gestion de base de données NoSQL.
  • Route : adresse permettant d'accéder à une fonctionnalité de l'API.
